# Olist 巴西电商用户增长与运营分析

基于 Olist 巴西电商平台公开数据，分析平台增长质量、用户留存与复购、用户价值以及配送和卖家体验表现，并将分析结果转化为可执行的运营建议。

## 项目背景

平台 GMV 增长并不一定代表增长健康。本项目围绕一个核心问题展开：

> **Olist 的增长是否健康？如果增长受限，问题出在哪里？如何通过提升用户留存和用户价值实现持续增长？**

分析重点：

- GMV 增长来自用户规模、购买频次还是客单价？
- 新用户首购后是否会回来？
- 哪些用户群体贡献了主要 GMV？
- 配送时效和卖家表现是否与用户评分存在关联？
- 平台下一阶段应该优先拉新、促复购，还是治理供给侧体验？

## 关键结论

### 1. 平台在峰值后进入横盘，增长质量偏弱

- 数据覆盖时间为 2016 年 9 月至 2018 年 8 月。
- 全周期包含 96,478 个订单、93,358 名用户，订单支付金额合计约 15.42 million。
- 2017 年 11 月 GMV 达到阶段峰值，为 1,153,528.05。
- 2018 年 7 月较峰值月 GMV 下降 10.9%，订单数下降 15.5%，活跃用户下降 15.1%，而 AOV 上升 5.5%。
- 月度购买频次长期约为 1.01，GMV 没有明显由复购驱动。

**判断：** 平台的问题在于用户增长放缓且存量用户没有形成持续购买。

### 2. 首购后的留存和复购是最大瓶颈

- 97.00% 的用户只购买过 1 次。
- 二购率为 3.00%，三购率为 0.24%。
- 平均购买次数为 1.0334 次。
- 具备完整观察窗口的 Cohort 平均次月留存率约为 4.96%，第 2 个月约为 0.29%。

**判断：** 平台需要从“持续获取一次性买家”转向“把首购用户转化为二购用户”。

### 3. 用户价值集中在少数高价值和潜力用户

按 RFM 业务规则划分：

| 用户分层 | 用户数 | 用户占比 | GMV占比 |
| --- | ---: | ---: | ---: |
| 高价值用户 | 6,451 | 6.91% | 13.06% |
| 潜力用户 | 7,398 | 7.92% | 9.07% |
| 新增用户 | 4,329 | 4.64% | 3.28% |
| 沉睡用户 | 55,252 | 59.18% | 58.16% |
| 其他活跃用户 | 19,862 | 21.28% | 16.37% |

**判断：** 高价值用户适合重点保有，潜力用户适合推动二购和升档；沉睡用户规模很大，但应先分层再开展召回，不能直接进行全量补贴。

### 4. 配送体验与评分存在明显关联

- 平均配送时长为 12.56 天，中位数为 10.22 天。
- 延迟订单率为 8.11%。
- 配送时长与评分的 Spearman 相关系数为 -0.2362。
- 评分 1 分订单平均配送 21.34 天、延迟率 37.94%。
- 评分 5 分订单平均配送 10.68 天、延迟率 3.00%。

**判断：** 配送时效和承诺达成是用户体验治理的优先抓手，但相关关系不能直接等同于因果关系。

### 5. 高 GMV 不等于高体验

部分高 GMV 品类和卖家同时存在较低评分或较长配送时长。例如：

- `cama_mesa_banho`：GMV 1,036,988.68，平均评分 3.88。
- `informatica_acessorios`：GMV 911,954.32，平均配送 13.23 天。
- 卖家 `7c67e1448b00f6e969d365cea6b010ab`：GMV 187,923.89，平均评分 3.33，平均配送 22.39 天。

**判断：** 平台不能只按 GMV 管理卖家，应同时关注评分、配送和延迟率。

## 数据说明

项目使用 [Olist 巴西电商公开数据](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce/data)，并在 SQL 阶段完成基础清洗和订单层、商品层分析表准备。

当前 Notebook 直接读取：

- `orders_clean.csv`：一行一个订单，主要用于订单数、用户数、GMV、留存、复购、RFM 和配送分析。
- `items_clean.csv`：一行一个订单商品，主要用于品类和卖家层面的 GMV、配送和体验分析。

需要注意不同数据粒度：

- 订单数、用户数、留存和复购应基于订单层。
- 品类、卖家和商品价格相关指标应基于商品层。
- `payment_value` 用于订单层 GMV 和 RFM Monetary。
- `price` 用于品类和卖家层商品 GMV。

## 运营建议

基于当前分析，建议按以下顺序推进：

1. **P0：提升首购到二购转化**
   - 按首购品类、订单金额和配送完成时间分组。
   - 在收货后 7、21、45 天进行分层触达。
   - 以首购后 60 天二购率作为核心指标。

2. **P1：经营高价值和潜力用户**
   - 对高价值用户提供重点保有和服务保障。
   - 对潜力用户开展关联推荐、二购券和组合购买测试。

3. **P1：治理高 GMV 低评分卖家**
   - 联合监控 GMV、评分、配送时长和延迟率。
   - 对重点卖家进行履约整改和整改前后对照评估。

4. **P2：优化高 GMV 品类体验**
   - 优先检查 `cama_mesa_banho`、`informatica_acessorios` 和 `moveis_decoracao`。
   - 进一步下钻到卖家和商品层，定位体验问题来源。

## 局限性

- 数据覆盖期截至 2018 年 8 月，不能代表当前市场状况。
- RFM 分析日位于数据末期，沉睡用户比例可能受观察窗口影响。
- Cohort 的远期留存只能用于具备完整观察期的用户群体。
- 配送时长与评分的关系为相关性分析，不代表严格因果关系。
